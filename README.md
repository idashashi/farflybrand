# FarFly — фирменный стиль

Сайт: `index.html`. Публикация через GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.

## Структура
- `index.html` — фирменный стиль, один файл: картинки и шрифты встроены внутрь
- `assets/logo/` — логотип, знак, название, аватары: SVG и PNG, тёмный и белый
- `assets/fonts/` — Oswald, Roboto Flex, Saira Extra Condensed и лицензии SIL OFL
- `assets/icons/` — фавикон и иконки 32, 180, 192, 512 px
- `assets/img/` — схемы и примеры из документа
- `assets/downloads/` — архивы для кнопок «Скачать»: логотип, шрифты, иконки, шаблоны, всё
- `templates/` — шаблоны A4: КП, смета, программа, письмо на бланке (HTML и PDF)
- `templates/instagram-guides/` — наложения с охранными полями для карусели, сторис и рилс (SVG, PNG)
